# NOIR — трезвый водитель и автомобильный консьерж

Адаптивный одностраничный сайт на русском языке в тёмной палитре с золотыми акцентами.

## Состав

- `index.html` — весь сайт: HTML, CSS, JavaScript и встроенное изображение Mercedes-Benz GLE W166 2018 года.
- Кнопка «Позвонить» открывает диалог с номером.
- Кнопка MAX показывает заглушку до подключения настоящей ссылки.
- Разделы: услуги, автомобиль, тарифы, привилегии, порядок заказа и контакты.

Сборка, Node.js, npm, база данных и серверное приложение не нужны. Внешние шрифты, CDN и сторонние скрипты не используются.

## Посмотреть локально

Откройте `index.html` в браузере. Либо запустите из папки сайта:

```bash
python -m http.server 8080
```

Откройте http://localhost:8080.

## Размещение на сервере с Nginx

На Debian/Ubuntu установите Git и Nginx, если их ещё нет:

```bash
sudo apt update
sudo apt install -y git nginx
sudo mkdir -p /var/www/noir
sudo git clone https://github.com/DasBassKatze/noir.git /var/www/noir
```

Создайте `/etc/nginx/sites-available/noir` и замените `example.com` своим доменом:

```nginx
server {
    listen 80;
    server_name example.com www.example.com;

    root /var/www/noir;
    index index.html;
    charset utf-8;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ /\. {
        deny all;
    }
}
```

Подключите конфигурацию:

```bash
sudo ln -s /etc/nginx/sites-available/noir /etc/nginx/sites-enabled/noir
sudo nginx -t
sudo systemctl reload nginx
```

Направьте DNS-запись A домена на IP сервера. Настройте HTTPS для своего домена средствами хостинга или сертификатом Let's Encrypt.

Если домена пока нет и сервер обслуживает только этот сайт, можно использовать `listen 80 default_server;` и `server_name _;`, предварительно отключив конфликтующий стандартный сайт Nginx.

### Обновление

```bash
sudo git -C /var/www/noir pull --ff-only origin main
```

Перезапуск приложения не требуется. При необходимости обновите страницу без кэша.

## Обычный хостинг

Загрузите `index.html` в корневую папку домена (`public_html`, `www` или `htdocs` — зависит от хостинга). Дополнительных файлов для работы страницы не требуется.

## Что заменить перед запуском для клиентов

В `index.html`:

1. Замените `+7 (XXX) XXX-XX-XX` настоящим номером и при необходимости добавьте ссылку `tel:+7...` в телефонную плашку.
2. Подключите реальную ссылку MAX вместо обработчиков `[data-max]`, открывающих демонстрационный диалог.
3. Укажите настоящие цены, город, зону обслуживания и часы работы.
4. Подтвердите состав бонусов и замените демонстрационные пояснения на фактические условия.
5. При необходимости замените название NOIR.
6. Замените сгенерированную иллюстрацию фотографией вашей машины: положите фото рядом с `index.html` и замените `src` у `.hero-bg` на путь к файлу. Второе изображение в блоке автомобиля автоматически использует тот же `src`.

Текущие цены и номер — примеры. Изображение автомобиля создано ИИ и не является фотографией реальной рабочей машины.

## Проверка

Главный экран, открытие телефонной плашки и заглушка MAX проверены в браузере. Для телефона предусмотрены адаптивная вёрстка и раскрывающееся меню. Развёртывание на вашем собственном сервере не выполнялось.
